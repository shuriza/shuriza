# Agent Instructions

Before doing broader work in this repository, read `.multibrain/session.md` first, then open the most relevant bucket in `.multibrain/indexes/`.

## Workflow
- Prefer short, reusable notes over long transcripts.
- After meaningful work, write back a short update to the matching bucket.
- If a decision, blocker, or handoff is important, add a deeper note in `.multibrain/context/`.

## Scope
- Keep this guidance repo-local and non-destructive.
- Do not treat this file as a replacement for task-specific docs or specs.
