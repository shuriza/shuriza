# WhatsApp Tic-Tac-Toe Bot

Bot game Tic-Tac-Toe untuk WhatsApp Group dengan perintah super simpel!

## Instalasi

```bash
cd wa-tictactoe
npm install
npm start
```

Scan QR Code yang muncul di terminal dengan WhatsApp (Settings > Linked Devices).

## Perintah

| Ketik | Fungsi |
|-------|--------|
| `ttt @nama` | Tantang pemain |
| `ok` | Terima tantangan |
| `ga` | Tolak tantangan |
| `1` - `9` | Pilih posisi (langsung ketik angka!) |
| `papan` | Lihat papan |
| `nyerah` | Menyerah |
| `skor` | Lihat statistik |
| `menu` | Bantuan |
| `reset` | Reset game |

## Cara Main

```
Kamu:   ttt @teman
Teman:  ok
Kamu:   5
Teman:  1
Kamu:   9
...dst sampai menang/seri!
```
